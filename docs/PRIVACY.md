# CleanNetwork plugin privacy policy

Effective November 26, 2026.

CleanNetwork is an instruction-only plugin published by alegelos. It contains
skills, guides, examples and tests for developers integrating the Swift and
Android SDKs.

## Publisher

The publisher operates no backend for the plugin and receives no project files,
credentials, prompts or telemetry from the package. The publisher does not
retain session data.

## Host application

The AI application running the plugin can read project files and API contracts
you provide while carrying out your request, subject to its permissions and
data policies. The host's data handling and retention policies apply to its
services. Consult your host application's policies for details.

## GitHub and other network services

Installing the plugin fetches its files. The public distribution source is
[GitHub](https://github.com/alegelos/CleanNetworkPlugin). GitHub's own policies
apply when you use its services.

If you explicitly build an example, its build tools fetch public development
dependencies from the sources declared in its build files. Those services have
their own data practices. The examples use fictional data and example.com URLs.
The bundled tests do not contact a production API. Your integration may use
endpoints and authentication supplied by your project, and the services you
contact handle data under their own policies.

## Contact

For questions, use [GitHub Issues](https://github.com/alegelos/CleanNetworkPlugin/issues).
Issues are public. The publisher can see your GitHub username and anything you
choose to post there and can use that information to respond to your issue.
Anyone can read a public issue, even after it is closed. GitHub hosts the
thread and manages retention on its platform. You can edit your comments.
Earlier versions may remain visible in the edit history. To request removal,
contact the maintainer through Issues with the issue number. Keep secrets,
credentials and personal data out of public issues.
